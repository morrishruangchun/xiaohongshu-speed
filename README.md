# 小红书视频倍速控制器

> 小红书视频播放倍速控制 + 自动最高画质

## 功能
- 🚀 多档倍速切换（0.5x ~ 5x）
- 🎬 自动切换最高画质
- 💾 记忆上次使用的倍速
- ⚙️ 支持自定义倍速档位
- 🖱️ 鼠标悬停显示，自动隐藏

## 安装
1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击 [安装脚本](https://raw.githubusercontent.com/morrishruangchun/xiaohongshu-speed/main/xiaohongshu-speed.user.js) 一键安装

## 使用
打开任意小红书视频，鼠标移入播放器即可看到控制条。
